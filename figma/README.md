# BiteMatch in Figma

The import creates a new page with editable text, shapes, images and prototype connections for mobile (390 px) and desktop (1,440 px). Its two example flows follow the same sweet, crispy, ₱0 pantry scenario.

1. Open a Figma **Design** file in Figma Desktop.
2. Choose **Plugins → Development → Import plugin from manifest** and select this folder’s `manifest.json`.
3. Run **BiteMatch prototype** from **Plugins → Development**.
4. Present the **Mobile** or **Desktop** flow from the start frame.

Pick **Sweet**, then **Something crispy**, and choose the **Budget** field to set it to ₱0 in this walkthrough. Select **Banana**, **Sugar**, and **Canola oil** to see **Banana chips**. Add **Ripe mango** before viewing matches to try skipping to a second card. Continue without the oil to try recovering from an empty result.

The clickable Figma example uses linked frames. The browser prototype supports arbitrary inputs within the sample catalog. The import script uses local assets and has network access disabled.
