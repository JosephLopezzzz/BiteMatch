# BiteMatch

A mobile and desktop prototype for finding food that fits what you’re craving and what you can spend today.

Open `index.html` in a browser to try it. It also works from a static web server. The prototype keeps answers in the current page session and uses five sample dishes with illustrative prices and calories. The food photos are generated for the prototype.

## Try the ₱0 flow

1. Pick **Sweet**, then **Something crispy**.
2. Enter **0** for the budget.
3. Select **Banana**, **Sugar**, and **Canola oil** from your pantry.
4. Choose **Banana chips**. Remove an essential ingredient to try the empty state.

On the results screen, swipe left to skip or right to pick. Buttons and arrow keys offer the same actions. Turn on your device’s reduced motion preference to preview the flow with animations removed.
